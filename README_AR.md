# ألفا بلو بوكس — النسخة المصححة للألوان والنصوص

هذه هي **نفس نسخة موقع V4 الأصلية** كما هي من دون إعادة تصميم، مع إصلاح تباين الألوان داخل الأقسام التي أرسلت صورها:

- الاقتباس على خلفية داكنة: صار الخط أبيض/عاجيًا واضحًا.
- عنوان «خدمات متكاملة»: صار داكنًا على الخلفية الفاتحة بدل الأبيض غير المقروء.
- عنوان «كل مرحلة محسوبة»: صار داكنًا على الخلفية الفاتحة.
- قسم «قيمنا»: النص والأزرار صارت فاتحة وواضحة مع حدود ذهبية هادئة.
- تحسين النصوص الثانوية في البطاقات دون تغيير المحتوى.

تم تنفيذ التصحيح في ملف `contrast-fix.css` المضاف **بعد** ملفات CSS الأصلية لتسهيل الرجوع عنه، مع الحفاظ على الصور والشعار والحركة وWebGL وجميع الأقسام وبيانات التواصل الموجودة.

## التشغيل

فك الضغط ثم افتح `index.html` في Chrome أو Edge. لعرض مشهد 3D عند وجود قيود على الملفات المحلية، افتح مجلد الموقع في موجه الأوامر وشغّل `python -m http.server 8000`، ثم افتح `http://localhost:8000`.

**ملاحظة:** صورة المبنى تصور توضيحي وليس مشروعًا منفذًا للشركة.
